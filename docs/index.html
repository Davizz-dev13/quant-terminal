About me

I live at two ends of the stack that rarely meet: low-level architecture, where code turns into clock cycles, and LLM systems, where code starts to look like thinking. The gap between those worlds is the point: I want to understand systems from top to bottom.

The same obsession pulled me into finance. I'm building Sharpe Lab, a quantitative strategy lab that tests every idea out of sample, with realistic costs, and then tracks it in real-time paper trading before trusting it with a single euro.

Away from the keyboard: cars. The incurable kind of passion.
